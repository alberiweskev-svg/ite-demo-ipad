# Collaudo calendario I.T.E. 4.0
Questa pagina e' un prototipo isolato: non importa anagrafiche, non accede al vault, non salva dati.
Aprire `ite-operations-demo.html` tramite un server statico HTTPS che serva anche gli script e il CSS dalla stessa directory.
## Prove
1. Caricare tre appuntamenti di esempio.
2. Filtrare per tecnico 1, tecnico 2 e tutti.
3. Filtrare per giorno; usare Tutti i giorni per rimuovere il filtro.
4. Spostare un appuntamento in una fascia occupata dallo stesso tecnico: deve comparire un errore.
5. Annullare un appuntamento e riprenotare la fascia liberata.
6. Aprire, chiudere e revisionare un intervento; controllare lo storico.
7. Stampare l'agenda con il filtro desiderato.
8. Azzerare la demo: appuntamenti e storico devono scomparire.
## Limitazioni
Dati esclusivamente fittizi e in memoria; al ricaricamento vengono persi. Nessuna autenticazione, archiviazione cifrata o collegamento alla versione 3.0.74. L'URL GitHub del file mostra il codice, non pubblica la demo. La stampa e' da verificare su iPad e desktop.
