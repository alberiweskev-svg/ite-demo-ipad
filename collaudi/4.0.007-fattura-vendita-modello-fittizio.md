# Modello di riconoscimento: fattura di vendita (4.0.007)

Stato: specifica e caso di test fittizio; estrazione OCR/PDF NON ancora implementata.
Fonte strutturale: esempio visivo fornito dall'utente; nessun documento originale né dato personale è conservato qui.

## Campi da estrarre
- tipo_documento: fattura_vendita
- numero_documento; data_emissione
- emittente: ragione_sociale, indirizzo, piva
- destinatario: ragione_sociale, indirizzo, piva/cf
- sede_spedizione (se presente)
- righe: articolo, descrizione, unita_misura, quantita, prezzo_unitario, imponibile, codice_iva
- riepilogo_iva: codice, riferimento_normativo, imponibile, aliquota, imposta
- totale_documento, termini_pagamento, scadenze, riferimenti_ordine
- dati_bancari: presenza (non proporre la memorizzazione automatica dell'IBAN)

## Criteri di accettazione
1. PDF testuale: estrazione locale senza invio a server esterni.
2. Fotografia/PDF scansione: OCR disponibile su iPad e desktop, oppure errore esplicito e fallback manuale.
3. Distinguere dati certi, incerti e mancanti; non inventare campi.
4. Mostrare anteprima di confronto con il documento originale.
5. Nessuna creazione o modifica di cliente, sede, articolo o fattura senza conferma.
6. Identificare duplicati con numero, data e emittente; non sovrascrivere silenziosamente.
7. Verificare somme e trattamento IVA senza presumere che IVA 0 significhi esenzione.
8. Backup completo include documento e metadati confermati.
9. Test su iPad Safari e Chromium desktop con soli dati fittizi.

## Esito
Specifica predisposta. Test applicativi NON ESEGUITI. Nessuna funzionalità OCR dichiarata operativa.
